# bobsgameonline (placeholder)

This repository is a **name placeholder** — it currently holds only this README and no code.

The actual "bob's game online" codebase — the original Java client and server, a 2D MMORPG engine and world — lives in [`bobsgameonlinejava`](https://github.com/robertpelloni/bobsgameonlinejava). The modern engines are [`bobsgameweb`](https://github.com/robertpelloni/bobsgameweb) (TypeScript/PixiJS) and [`okgame`](https://github.com/robertpelloni/okgame) (C++), tied together in the [`bg`](https://github.com/robertpelloni/bg) umbrella workspace.
